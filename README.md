## Requirements

- Node.js 20.19+
- npm 10+
- Expo CLI through `npx expo`

## Install

npm install

## Run

npm run start

Then press:
- i for iOS
- a for Android
- w for web

## Notes

- Expo SDK 55, React Native 0.83, React 19.2
- Data moved into src/data
